toString() - it makes what i wrote in the edit text into a string that I can use. The edited texts are the student ID number and the password.
substring - it gets a portion of the string starting where i want it to be. I used this in getting the last two digits of the student ID number.
length() - I used this to get the length of the student ID number to get the last two digits.
equals - I used this to compare two strings. In this case the correctpassword(color plus last two digits) and the written password in the edited text.
